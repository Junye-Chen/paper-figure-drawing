# Planning budgets (uncalibrated)

Estimate the current stage first, then optional remaining work. These ranges are input + output planning estimates, not metered usage or promises.

| Stage | Approximate tokens |
|---|---:|
| Method interpretation and emphasis candidates | 2k–5k |
| Visual-language options and core sketch | 3k–8k |
| Whole-figure composition | 3k–7k |
| Style samples, only if needed | 2k–5k |
| Polish, editable export and visual checks | 5k–12k |
| Local revision with usable scene | 2k–6k/round |

A standard interactive task may total about 15k–40k; complex assets, long papers or repeated redesign can exceed this. Stages share context, so these are not precise additive billing estimates. Confirmed earlier stages need not be repeated. Multiple figures can share interpretation and style work but require figure-specific core and layout decisions.

Image generation charges and image accounting are separate. Exporting PPTX and SVG from one scene does not double design cost. User budgets override estimates; reduce options or optional details before cutting verification. Without usage telemetry, do not claim exact consumption or budget enforcement.

Do not generate alternatives, style samples or repeated approval rounds to fill this budget. Reuse established reference/style decisions. Completion is a clean editable handoff, not exhausting the estimated allowance through cosmetic changes.

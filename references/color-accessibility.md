# 低饱和、色觉友好的视觉系统

用户偏好：低至中饱和标注、克制的背景和强调色；兼顾色盲、色弱与低视力读者。避免荧光色、大面积高饱和背景和只靠红绿区分。不能把降低饱和度或“蓝橙配色”当作无障碍证明。

## 语义先于色号

- 一项关键区别至少同时有颜色之外的可见线索：直接标签、形状、实/虚线、纹理或位置分组。例如类别 A=圆点/实线、类别 B=方点/虚线、类别 C=三角/点划线。
- 淡填充只作分区，核心边界和文字用足够深的色。低饱和不等于低对比。
- 优先 1 个主色、1 个强调色和中性色。额外类别用位置、符号和文字分担，不为每个模块引入新颜色。
- 保留科学照片的原始颜色；只调框线、标签与示意图，不为了统一审美改实验内容。

## 起始色板（设计候选，不是经色觉模拟认证的通用安全色板）

| 角色 | 色号 | 冗余编码建议 |
|---|---|---|
| 正文 | #263542 | 直接标签 |
| 次要说明 | #52616B | 字级层级，不能过小 |
| 主关系：灰蓝 | #496B88 | 实线＋圆点 |
| 当前/强调：棕橙 | #A07855 | 虚线＋方点 |
| 可选第三类：灰紫 | #766A88 | 点划线＋三角 |
| 画布 / 面板 | #FFFFFF / #F3F5F7 | 不承担类别含义 |
| 淡填充 | #E8EEF3 / #F2EBE4 | 搭配对应深色边框 |

实测：棕橙 #A07855 在白底为 3.953:1、浅灰面板为 3.617:1，适用于必要图形的粗线/边界，不用于小字号正文；文字使用 #263542 或 #52616B。完整数值见 assets/palette-contrast.json。

选择灰蓝与棕橙并不保证它们在灰度下可区分，必须保留线型/形状。不要将浅色填充直接当细文字色。

## 检查与记录

1. 用实际前景/背景色计算亮度对比；正文目标至少 4.5:1，解释所必需的非文字边界/线条以 3:1 为参考。这里借用 WCAG 的工程阈值，不宣称这是 CVPR 投稿标准或整张图认证。
2. 检查最终尺寸、灰度预览及红色盲、绿色盲、蓝黄色觉缺陷模拟。使用经过说明的模拟器，记录工具/模型/严重程度；不可把简单去饱和叫作色盲模拟。
3. 在模拟图中核对每一组语义是否仍可追踪，而不是只检查色块好不好看。看不清时优先改标签/形状/线型与明度，再换色相。
4. 未执行模拟就写 pending，不能称“已通过色盲验证”。模拟也不等同于真实用户测试。
5. 风格确认时展示同内容的原色、灰度与可用模拟图；颜色缺陷不能留到最终排版才发现。

依据：[W3C 颜色不能是唯一线索](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html)、[文字对比](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)、[非文字对比](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)。本次只计算候选色板对比；不代表任何具体论文图已符合这些规则。
